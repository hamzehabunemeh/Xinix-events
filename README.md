# XINIX Events — Website v3

Responsive single-page English website for XINIX Events, styled to match the selected black, cyan, and neon-magenta concept.

## Files
- `index.html` — page content and navigation
- `styles.css` — layout, visual styling, and responsive behavior
- `script.js` — mobile navigation and current year
- `assets/hero-stage.jpg` — nightclub stage background image
- `netlify.toml` — Netlify static-site publish configuration

## Deploy on Netlify
No build command is required. Set the publish directory to `.`.

## Update the GitHub repository
Upload/replace `index.html`, `styles.css`, `script.js`, `netlify.toml`, and `README.md` in the repository root. Upload/replace `assets/hero-stage.jpg` inside the existing `assets` folder. Keep the filename and folder path exactly as shown.

## Before launch
Replace `hello@xinixevents.com` with the confirmed business email. Add real social links and only confirmed event details. No event dates, artists, venues, ticket prices, phone numbers, or social handles are invented here.
